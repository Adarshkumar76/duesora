# Architecture Decision Records

Use ADRs for decisions that are expensive to reverse or affect
contributors.

Location:

``` text
docs/adr/0001-use-postgresql.md
```

Template:

``` markdown
# ADR NNNN: Title

## Status
Proposed / Accepted / Superseded

## Context
What problem are we solving?

## Decision
What did we decide?

## Alternatives
What else was considered?

## Consequences
Benefits, costs, risks, migration impact.
```

Examples requiring an ADR:

-   ORM selection;
-   authentication architecture;
-   queue technology;
-   license change;
-   plugin system;
-   public API versioning;
-   encryption approach;
-   multi-tenancy model.
