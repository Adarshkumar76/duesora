# Branding

## Name

Duesora

## Tagline

**Know what you own. Know what's due.**

## Brand meaning

The product identity should communicate:

-   awareness;
-   tracking;
-   timely action;
-   ownership;
-   reliability;
-   calm operational control.

## Logo

Maintain source/vector assets plus:

-   light-background icon;
-   dark-background icon;
-   monochrome icon;
-   favicon;
-   app icon;
-   social/GitHub avatar.

Do not stretch, recolor randomly, add effects, or combine the official
mark with unrelated symbols.

## Naming ecosystem

-   Duesora Server
-   Duesora Web
-   Duesora Worker
-   Duesora CLI
-   Duesora API
-   Duesora SDK

Use consistent capitalization: **Duesora**.
