# UX and Accessibility

## UX principles

-   important information first;
-   show urgency without panic;
-   distinguish detected data from user-entered data;
-   explain automation failures;
-   make destructive actions reversible where possible;
-   keep advanced configuration optional.

## Accessibility

Target WCAG 2.2 AA:

-   semantic HTML;
-   keyboard operation;
-   visible focus;
-   accessible form labels/errors;
-   sufficient contrast;
-   reduced-motion support;
-   logical heading structure;
-   screen-reader-friendly status messages;
-   charts must not rely on color alone.

## Responsive design

Core resource, renewal, and acknowledgement workflows must work on
mobile widths even if administration is optimized for desktop.
