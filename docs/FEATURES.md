# Feature Catalogue

## MVP

-   authentication;
-   personal workspace;
-   organization workspaces;
-   resource CRUD;
-   categories and tags;
-   ownership;
-   renewal/expiry dates;
-   recurring costs;
-   dashboard;
-   reminder engine;
-   in-app notifications;
-   SMTP email;
-   signed webhooks;
-   CSV/JSON import/export;
-   Docker Compose;
-   health checks.

## Monitoring

-   TLS certificate expiry detection;
-   domain registration/expiry metadata where reliably available;
-   monitor history;
-   check failure state;
-   configurable schedules;
-   safe retry/backoff;
-   change detection.

## Team features

-   invites;
-   owner/admin/member/viewer roles;
-   teams;
-   resource ownership;
-   audit events;
-   escalation;
-   bulk assignment.

## Cost intelligence

-   original amount/currency;
-   normalized monthly/yearly cost;
-   cost history;
-   budgets;
-   renewal cash forecast;
-   price-change alerts;
-   planned cancellation;
-   unused/under-review status.

## Integrations

Prioritize open protocols:

-   SMTP;
-   generic webhooks;
-   iCalendar export;
-   CSV/JSON;
-   ntfy/Gotify.

Optional later:

-   Slack;
-   Discord;
-   Telegram;
-   GitHub;
-   cloud/provider adapters.

## Advanced

-   document/invoice extraction with user confirmation;
-   seat/usage intelligence;
-   dependency graph;
-   API keys;
-   public API;
-   CLI;
-   plugin SDK;
-   OIDC;
-   2FA;
-   internationalization.
