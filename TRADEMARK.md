# Duesora Name and Logo Policy

The source code is licensed under the MIT License. The project name,
logo, and other brand assets are separate from the software license.

Until a formal trademark policy is adopted:

-   forks may truthfully state that they are based on Duesora;
-   modified distributions should not imply official endorsement;
-   do not use the Duesora name/logo in a way that confuses users about
    who operates a service;
-   preserve attribution where required by the software license;
-   unofficial hosted services should clearly identify themselves as
    unofficial.

This file is a project policy draft, not legal advice or a statement
that a trademark has been registered.
