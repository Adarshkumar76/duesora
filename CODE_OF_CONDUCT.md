# Code of Conduct

## Our standard

Duesora aims to maintain a professional, respectful, technically
constructive community.

Expected behavior includes:

-   treating contributors with respect;
-   discussing ideas and code rather than attacking people;
-   giving actionable review feedback;
-   respecting privacy and security disclosures;
-   avoiding harassment, discrimination, threats, spam, and deliberate
    disruption.

## Enforcement

Maintainers may edit, remove, reject, lock, or moderate contributions
and interactions that violate these standards. Repeated or severe
violations may result in temporary or permanent exclusion from project
spaces.

## Reporting

For community conduct concerns, contact the project maintainers through
a private project communication channel. Do not use the security
vulnerability channel unless the report concerns a security issue.

This is a project-specific lightweight policy. The maintainers may later
adopt a standard community code such as Contributor Covenant with its
required attribution.
