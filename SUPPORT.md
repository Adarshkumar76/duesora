# Support

## Where to ask

-   Bugs: GitHub Issues using the bug template.
-   Feature requests: GitHub Issues/Discussions using the feature
    template.
-   Usage questions: GitHub Discussions when enabled.
-   Security vulnerabilities: follow `SECURITY.md`.

## Before opening an issue

Include the Duesora version, deployment method, OS/runtime, relevant
configuration with secrets removed, logs with secrets removed, and
reproduction steps.
